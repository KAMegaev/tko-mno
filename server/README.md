# МНО: локальные файлы и серверный шлюз ИИ

Адрес: https://mno.megaev.ru. Node.js 22+, порт 127.0.0.1:8788.

## Передача данных

Excel-файлы читаются, сопоставляются и рассчитываются в браузере пользователя.
Готовая книга и отчёт создаются там же. Исходные файлы, строки реестра и готовые
книги не загружаются на сервер. Сервер больше не имеет маршрутов загрузки,
сборки и скачивания файлов, не создаёт временные каталоги с материалами.

Только по кнопке «Уточнить с помощью ИИ» браузер передаёт в /api/ai:
- task=columns, table и массив заголовков titles; либо
- task=matches и два списка registryNames/templateNames.

Сервер проверяет форму и размер запроса (до 128 КБ), задаёт правила и модель,
обращается к OpenAI и возвращает структурированные подсказки.
Исходные данные запросов не записываются приложением в файлы или журналы.
Обработка Excel работает и при недоступности сервера ИИ.

API-ключ хранится в /etc/tko-mno.env (root:tko-mno, 0640).
Пользователь его не вводит. Браузер не обращается к OpenAI напрямую.
Модель по умолчанию gpt-4.1-mini. Лимит экземпляра: 60 обращений в час,
два одновременно; до 512 заголовков, 250 исходных и 2500 целевых наименований.

## Установка и обновление

Используются прежние systemd-сервис tko-mno и Nginx для mno.megaev.ru.
Настройки Node.js, ключа и HTTPS сохраняются. Новый код доставляется
существующим GitHub Actions из ветки claude/waste-accumulation-calculator-t45mxe.

Первичная установка: bash /opt/tko-mno/server/deploy/install.sh.
Ограниченный SSH-доступ GitHub: bash /opt/tko-mno/server/deploy/setup-github.sh.
Secrets репозитория: VPS_SSH_KEY и VPS_KNOWN_HOSTS.
Actions variable: MNO_DEPLOY_ENABLED=true.

Деплой проверяет тесты, перезапускает только МНО и проверяет /healthz по HTTPS.
При ошибке возвращает предыдущий коммит. Изменение Nginx/systemd и
привилегированного deploy-скрипта выполняет администратор отдельно.

## Проверки

node --test server/test/*.test.js
OUT=/tmp/mno-output.xlsx node tools/run.mjs
PUBLIC_ORIGIN=http://127.0.0.1:8765 PORT=8765 node server/index.js
BASE=http://127.0.0.1:8765 node tools/e2e.mjs

Браузерный тест блокирует все серверные API во время обработки Excel.
После сохранения результатов отдельно проверяет, что кнопка ИИ отправляет
только массивы заголовков, без книг, содержимого строк, ключей или результатов.
